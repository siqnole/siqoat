# Siqoat

A modern, cute enhancement layer for Stoat. The visual language is mono-gray with purple, lilac, and soft lavender accents.

## Current scaffold

- `siqoat.user.js` — the only script to install in Tampermonkey
- `manifest.json` — project metadata
- `themes/` — installable or loadable theme packages
- `plugins/` — future plugin packages

## Install

1. Install `siqoat.user.js` in Tampermonkey.
2. Open or reload `https://stoat.chat/app`.
3. Click the small sparkle button in the lower-right corner.

The current version is intentionally a clean host scaffold. It establishes the Siqoat palette and UI language before adding the settings-integrated theme and plugin manager.
